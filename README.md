# Portfólio · Sofia de Abreu

Portfólio em página única feito com React 18, Vite, TypeScript e Tailwind CSS 3.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

O projeto inclui animações com GSAP/ScrollTrigger e Framer Motion, partículas com tsParticles, rolagem suave com Lenis e cenas 3D com Three.js e React Three Fiber. O deploy na Vercel usa o `vercel.json` incluído.
